# 华为 PC 营销软文智能体

自研 Agent 闭环:场景解析 → 平台策略 → 知识库检索(事实与图片)→ 事实点提取 → 图文编排 → 软文生成 → 事实与图片核验 → 合规检查 → 导出。

知识库(ima)只提供华为产品事实和图片素材,软文由本项目的 Agent 生成。

## 快速开始

```bash
py -m pip install -r requirements.txt
cp .env.example .env   # 然后在 .env 填入自己的值,不要提交
```

环境变量见 `.env.example`。所有密钥只放环境变量,不写入源码、日志、截图。

## 检索实现

- `LocalRetriever`:读本地知识库副本(`LOCAL_KB_ROOT`),开发期使用。
- `ImaRetriever`:调用 ima 官方接口,提交前切换并跑全量测试。
- 两者实现同一个 `Retriever` 接口,上层代码不需要改。

## 核验与合规

C 模块负责软文的质量把关:

- **事实核验**(`agent/verify.py`):检查型号一致性、数值依据、限定条件、待复核字段。
- **图片核验**:确保每张图来自知识库、型号一致、来源完整。
- **合规检查**(`agent/compliance.py`):扫描禁用词(50+ 条)、价格护栏、虚假承诺、竞品贬低。
- **价格护栏**:金额必须在 price_records 中,必须带类型和日期,拦截国补/教育优惠/以旧换新(知识库无数值)。
- **自动改写**:尝试删除禁用词并复检,最多 2 轮,改不过的交给人工。

禁用词表:`data/banned_terms.yaml`,从知识库提取,支持正则和上下文例外。

## 运行界面

启动 Gradio Web 界面:

```bash
py app.py
# 访问 http://localhost:7860
```

界面提供:
- 输入:产品(必填)、人群、场景、平台、临时要求
- 输出:四段统一格式(场景判断 / 知识库依据 / 图文软文 / 核验结果)
- 导出:Markdown 和纯文本格式,含核验报告
- 状态:知识库连接状态,阻断警示,异常提示
