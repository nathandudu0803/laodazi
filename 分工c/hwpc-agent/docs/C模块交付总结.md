## 💡 关键设计决策

### 1. 为什么用 YAML 而不是数据库？
- 易于维护和版本控制
- 支持注释和说明
- 无需额外依赖

### 2. 为什么核验分两步（verify + compliance）？
- 职责分离：事实核验关注"对不对"，合规检查关注"能不能"
- 独立复用：B 生成时可先调 verify，确认无误再调 compliance
- 并行测试：D 可以分别测试核验能力和合规能力

### 3. 为什么自动改写只删除不生成？
- 安全优先：生成可能引入新错误
- 人工决策：复杂表述需要人工判断
- 透明可控：删除后的空缺清晰可见

### 4. 为什么界面不显示图片？
- 路径问题：本地路径在 Gradio 中不可访问
- 时间限制：图片预览需要额外处理（base64 或复制）
- 优先级：核验能力优先于展示效果
