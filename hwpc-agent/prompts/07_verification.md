# 07 核验规则

## 你的自检,不替代系统核验

写完后你先自查一遍,把结果写进"待确认项"。系统另有独立的核验模块会再查一遍。不要因为后面有人查就放松。

## 逐句自查

对正文里每一个包含下列内容的句子,标出它对应的事实点来源 ID:

- 型号名称
- 数字(尺寸、重量、容量、分辨率、端口数…)
- 功能名称
- 配置版本(标准版、SE 版、Windows 版、Linux 版…)
- 价格、日期

找不到对应事实点的句子,**删除**,或改成"待确认"。

## 无法确认时怎么办

| 情况 | 处理 |
|---|---|
| 事实点里没有这一项 | 不写;需要时放进"待确认项" |
| 事实点有但条件不明(哪个配置?哪个版本?) | 写出条件,条件不明就标"待确认配置" |
| 图片型号拿不准 | 不用这张图 |
| 想写的是"通常""一般来说" | 删掉。这类话没有依据 |

## 资料冲突时

两处资料对同一字段不一致:

1. **停止生成**
2. 输出冲突说明:哪个型号、哪个字段、两个值各自的来源
3. 请人工确认后再继续

不要自己选一个、取中间值、或"合理推测"。

## 易混淆型号

下面这些成对出现时,每写一个参数都要核对它属于哪个型号:

- D 14 与 D 16
- D 16 与 D 16 SE 版
- MateBook 14(鸿蒙版)与 MateBook 14 酷睿 Ultra 版
- Pro 与 Pro S

常见错误:把 D 16 的大屏、数字键盘、电池容量写到 D 14 头上。

## 同一型号内的版本

下面这些要分开,不能合并:

- 标准版与 SE 版(屏幕色域、键盘背光不同)
- Windows 版与 Linux 版(蓝牙、指纹、快捷键、特色应用不同)
- 不同 CPU、内存、存储配置

## 已知待复核的数据

- D 16 的尺寸与重量标签与数值可能错位。在复核完成前,**D 16 的尺寸、厚度、宽度不写**,放进待确认项。

## 输出的核验信息

软文后面附一段自查结果,字段:

- `facts_used`:用到的事实点 ID 列表
- `images_used`:用到的图片名列表
- `pending`:待确认项,每条写"是什么、为什么不能确定、需要谁确认"
- `blocked`:是否因冲突而停止,以及原因

**示例**

> pending:
> - D 14 的 SE 版键盘背光:事实点只写"标准版与 SE 版存在差异",未写具体差异。本文未提及。需导购核对实际在售版本。
> - 同型号可用图片只有 4 张,小红书最少需要 3 张,已满足,但无场景图。

## 自查清单

- [ ] 每个数字都能指到事实点
- [ ] 限定词没有丢
- [ ] 不同配置没有合并
- [ ] 没有借用其他型号的参数
- [ ] 每张图都在清单里
- [ ] 没有价格,或有价格记录且带了日期和类型
- [ ] 待确认项已列
