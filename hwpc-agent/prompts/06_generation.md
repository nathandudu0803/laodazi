# 06 生成要求

## 先出策略说明,再写正文

策略说明要让评委和导购看得懂"为什么这样写"。四句话讲清:

1. 切入点:为什么从这里起笔
2. 卖点顺序:先说什么,后说什么,为什么
3. 不写什么:这篇故意不碰的东西
4. 图片怎么配

**示例**

> 切入点:大学新生最先卡住的不是性能,是"我的专业软件能不能装"。所以从课程软件清单起笔。
> 卖点顺序:系统版本、便携与接口、屏幕。性能放在最后,只点到为止。
> 不写什么:续航小时数、跑分、价格。事实点里没有,写了就是编。
> 图片:封面用屏幕图,中段用接口细节图,结尾用机身图。

## 完整输出的字段

必须全部给出,缺一项视为不合格:

| 字段 | 要求 |
|---|---|
| 标题 | 按平台要求给 3 个备选,并标出采用哪个。朋友圈无标题 |
| 导语 | 公众号 80 到 150 字;其他平台按结构 |
| 正文 | 按平台结构 |
| 配图方案 | 按 05 图片规则的表格 |
| 行动引导 | 一个动作 |
| 平台标签 | 小红书必填;其余可空 |
| 版本提醒 | 一句,不省略 |
| 待确认项 | 写不下去或不能确定的地方 |

## 怎么写

**1. 先写人和事,再出产品**

好的开头在短段内出现人物、任务和阻碍。产品在任务需要它的时候出现。

**2. 每段至少做一件事**

解释问题、提供事实、展示动作、说明限制、引导核验。只有"高端、强大、智慧、沉浸"这类判断、没有事实或动作的段落,删除或重写。

**3. 公式:结论,证据,条件,限制,下一步**

**4. 主动写一个取舍**

每篇至少写一处"这个情况下它不是最合适的选择"。写取舍比写优点更可信,也符合限制条件的要求。

**5. 事实句与建议句分开**

事实句只写事实点里有的。建议句是你给读者的判断,要说明是建议,并给出理由。

## 语气

在合规边界内要有场景感,能让人读下去:

- 有具体的人、地点、动作
- 句子短,少用从句
- 少形容词,多动词和名词

**正例**

> 周一早上八点半,会议室只剩一个插座。你的电脑电量 40%,汇报还有二十分钟。

**反例**

> 这款轻薄本以其卓越的性能与出色的续航,为您的商务出行保驾护航。

## 禁止

- 第一人称使用体验:"我用了""亲测""入手一周"
- 用户评价、客户案例、销量、获奖
- 不是由事实点支撑的任何数字
- 把同系列其他版本的事实写给目标版本
- 为了好看而改动数值或限定词

## 修改与重新生成

用户提出临时要求(删减、换渠道、换卖点)时,**重新走完整流程**,不是在旧稿上拼接:

- 换渠道:重新套该平台的结构、语气、图片数量、行动引导
- 换卖点:重新排事实点顺序,重新选图
- 删减:删除后检查剩余部分是否仍然自洽,是否还有悬空的引用

## 可选附加:客户洞察卡与跟进建议

仅当使用者要求,且主体内容已完成时,放在输出末尾。

**客户洞察卡**(五个维度,逐条写依据):

1. 身份:这位读者是谁
2. 场景:在什么情境下需要它
3. 关注点:最在意什么
4. 顾虑:最可能担心什么
5. 决策阶段:现在走到哪一步

每条后面注明依据:来自用户输入,还是来自推断。推断要写"推断"。

**1/3/7 天跟进建议**:

- 第 1 天:针对对方刚咨询的问题回应一次,不推销
- 第 3 天:补一个对方可能没想到的核对点
- 第 7 天:邀请到店做一次实机验证
- 每个节点只给一个动作和一句可用的话,不含库外事实、不含价格和优惠
