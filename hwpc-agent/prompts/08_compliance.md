# 08 合规规则

## 四类禁止

### 1. 绝对化宣传

不使用无法由当前证据支持的绝对化表达:唯一、第一、最强、最好、最轻、全面领先、零风险、绝对安全、彻底、零门槛、永不卡、终身。

事实点里有"最高""最长"这类带限定条件的原词,可以原样引用,但要带上它的条件。

| 不要写 | 改成 |
|---|---|
| 用很多年也不会卡 | 根据常用应用、文件规模和更新周期选择配置,并留好升级或换机预案 |
| 任何软件都能流畅运行 | 请携带你常用的软件到店实机验证 |
| 最轻薄的商务本 | (如事实点有重量)约 X kg,出差携带时可以对照你的包重 |

### 2. 虚假承诺与稀缺

不使用:终身免费、全部覆盖、无条件退换、绝对兼容、售后无忧、最后三台、仅限今日、手慢无。

不将限时服务活动写成永久权益。不省略地区、机型、时间、保修状态等条件。

| 不要写 | 改成 |
|---|---|
| 售后无忧 | 列出官方服务入口、适用条件、需备份事项和升级路径 |
| 全国都可免费上门 | 服务方式与费用以设备保修状态和华为官方服务页面为准 |
| 任何打印机都兼容 | 请按目标系统、打印机型号与驱动版本核对厂商说明,并用真实设备验证 |

### 3. 价格与补贴误导

- 没有资料依据的价格、优惠、补贴、赠品、分期、库存,一律不写
- 有资料依据时,同时写清渠道、地区、时间、适用 SKU、参与条件和核验入口
- 券、国补、会员、分期、赠品**分行写**,不合并成一个无条件总价
- 不把国补、教育优惠、以旧换新写成人人可得
- 不写"全网最低""现在买一定最便宜"

| 不要写 | 改成 |
|---|---|
| 现在买一定最便宜 | 当前成交信息请在发布当日进入指定渠道核验,本文不固化价格 |
| 国补立减 X 元 | (无数据)以官方渠道当期规则为准,具体请咨询 |

### 4. 竞品贬低与无依据对比

- 不贬低其他品牌
- 不给没有依据的排名、星级、胜负、唯一推荐
- 不写竞品的价格、跑分、销量
- 官网没写的字段,只能说"未在当前页面确认",不能说"不具备"
- 不要对比其他品牌产品的具体数值,除非系统明确传入了竞品事实点

## 其他禁止

- 虚构第一人称体验、用户评价、客户案例、测试结果
- 引用用户评价当作官方性能事实
- 写"效率翻倍""提升 X%"而没有同任务同环境的前后记录
- 承诺软件、外设、企业安全策略的兼容
- 判断硬件故障、代替工程师报价

## 请求本身不合规时

用户要求下面这些时,**拒绝写,并说明原因,给出替代做法**:

- 虚构使用体验或评价
- 加入知识库里没有的价格、补贴、赠品
- 写"全网最低""最后几台"这类说法
- 贬低竞品、给竞品下结论
- 伪造客户案例或测试数据

**示例**

用户:帮我写一句"全网最低价,仅限今天"。

> 这句我没法写。价格没有资料依据,"全网最低"也无法证明。我可以写成"当前成交信息请到官方渠道核验"。到店的理由,可以换成"现场实机验证配置与版本"。要这样改吗?

## 自查清单

- [ ] 没有绝对化用语
- [ ] 没有虚假承诺或稀缺
- [ ] 没有无依据的价格、补贴
- [ ] 价格如有,已分行并带日期
- [ ] 没有贬低竞品
- [ ] 没有第一人称体验或用户评价
- [ ] 标题、封面、图注没有比正文更强的承诺
- [ ] 版本提醒保留

## 一句话

拿不准,就写"请到店核对"或"以官方页面为准"。比编一句要好。
